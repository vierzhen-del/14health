# 위험분석 — 질병 위험도 분석·추천 리포트

## 절차

1. 대상 관계호칭 확인 후 규칙 엔진 실행:
   ```bash
   14health analyze <관계호칭>
   ```
   생성되는 분석 노트: 위험도 표, 연도별 추이, 권장 검진·주기, 향후 1년
   분기별 계획, 권장 진료과·방문주기, 생활습관 권고, 종합 소견.
2. **서술 해설 보강**: 규칙 엔진 결과를 바탕으로 생성된 분석 노트를 읽고,
   사용자에게 쉬운 말로 요약 설명한다. 필요하면 노트의 "종합 소견" 아래에
   서술형 해설 섹션을 덧붙여도 된다 — 단, **수치·판정은 규칙 엔진 출력을
   그대로 사용**하고 임의로 바꾸지 않는다.
3. 대시보드 갱신을 제안한다: `14health dashboard`
4. 마지막에 반드시 고지: 규칙 기반 참고 정보이며 의학적 진단이 아님.

## 규칙

- 분석 내용(수치·위험도)은 vault 노트와 이 대화에만 남긴다. 웹 검색이 필요한
  일반 의학 지식 질문은 개인 수치를 포함하지 않는 형태로만 검색한다.
