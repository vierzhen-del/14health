# github-작업 — 14health

## ⚠️ 커밋 전 필수 확인

이 저장소는 **도구 코드만** 담는다. 건강 데이터는 저장소 밖 옵시디안 vault에 있다.

커밋하기 전에 스테이징 목록을 눈으로 확인한다:

- 수치(혈압·혈당·체중 등)·증상·처방약·진단·분석 본문이 포함된 파일이 없는가
- 실명이 들어간 파일이 없는가
- vault 경로가 저장소 안을 가리키게 된 설정 파일이 섞여 있지 않은가 (`14health config show` 로 확인)
- 테스트 산출물이 실제 사용자 설정을 참조하지 않는가 (`HEALTH14_CONFIG` 로 격리돼 있다)

하나라도 걸리면 커밋하지 말고 사용자에게 알린다.

## 푸시·PR

- `git push -u origin <branch>`. 네트워크 실패 시에만 2s → 4s → 8s → 16s 지수 백오프로 최대 4회 재시도.
- PR은 사용자가 명시적으로 요청할 때만 만든다.
