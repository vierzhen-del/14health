# 검진분석 — 이미지/첨부파일 판독 입력

검진 결과지 이미지를 Claude가 직접 판독해 구조화하고 vault에 저장한다.
(모든 판독은 이 세션 안에서 이루어지며, 이미지를 외부 서비스로 보내지 않는다.)

## 절차

1. **이미지 확보**: 첨부 이미지를 Read 도구로 읽는다. 폴더가 지정되면 폴더 내
   이미지 파일(jpg/png)을 모두 읽는다.
2. **판독**: 검진 항목·수치·단위·검진연도를 추출한다. 표준 항목명으로 정규화:
   수축기혈압, 이완기혈압, 공복혈당, 당화혈색소, 체중, 신장, BMI, 허리둘레,
   총콜레스테롤, LDL, HDL, 중성지방, AST, ALT, 감마GTP, 크레아티닌, 혈색소.
3. **익명화**: 결과지의 실명·주민번호·전화번호는 추출하지 않는다.
   대상은 반드시 관계호칭으로 사용자에게 확인한다.
4. **확인**: 추출한 수치 표를 사용자에게 보여주고 저장 전 확인받는다.
5. **저장**: 구조화 JSON을 임시 파일로 만들어 저장한다:
   ```bash
   14health note write <관계호칭> --json <임시파일>
   ```
   JSON 형식:
   ```json
   {"type": "checkup", "year": 2025, "date": "2025-11-02",
    "metrics": {"수축기혈압": 138, "공복혈당": 115, "체중": 80},
    "memo": "결과지 특이사항 요약"}
   ```
   진료 기록 이미지(처방전·소견서)라면:
   ```json
   {"type": "visit", "date": "2026-07-01", "hospital": "내과",
    "symptoms": ["기침"], "diagnosis": "감기", "medications": ["약이름"]}
   ```
6. 저장 후 `/위험분석` 실행을 제안한다. 임시 JSON 파일은 삭제한다.
