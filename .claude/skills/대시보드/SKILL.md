# 대시보드 — 시각화·공유

## 대시보드 생성/갱신

```bash
14health dashboard
```

- `<vault>/대시보드.html` 생성 — 단일 파일, 외부 네트워크 요청 없음.
- 구성: 가족 건강 현황 카드(홈) → 구성원 탭 선택 시 상세 차트·위험도·추천,
  연도별 분기 검진 계획, 생애주기 검진 타임라인.
- 생성 후 사용자에게 파일 경로를 알려주고 브라우저로 열도록 안내한다.

## 카톡 공유 이미지

```bash
14health share <관계호칭>
```

- `<vault>/90-내보내기/` 에 요약 카드 PNG 생성 (관계호칭만 표기, 실명 없음).
- 사용자가 카카오톡에 **직접 첨부**해 공유한다 — 자동 전송 기능은 없다(로컬 전용 원칙).
- Pillow 미설치 시 대시보드 HTML의 "공유 이미지 저장" 버튼을 안내한다.
