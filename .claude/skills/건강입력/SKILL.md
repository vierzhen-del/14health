# 건강입력 — 대화형 건강 데이터 입력

사용자와 대화하며 건강 데이터를 수집하고 `14health` CLI로 옵시디안 vault에 저장한다.

## 절차

1. **대상 확인**: 누구의 기록인지 관계호칭으로 확인 (나/부인/아들/딸/어머니 등).
   등록 여부는 `14health member list` 로 확인하고, 없으면 출생연도·성별을 물어
   `14health member add <관계호칭> --birth <연도> --sex <M|F>` 로 등록한다.
2. **데이터 유형 판단**:
   - 검진 수치 → `14health checkup add <관계호칭> --year <연도> --field 항목=수치 ...`
     (혈압은 `--field 혈압=120/80` 형태 지원, 신장+체중 입력 시 BMI 자동 계산)
   - 진료 기록 → `14health visit add <관계호칭> --date <YYYY-MM-DD> --hospital <병원종류> --symptom <증상> --diagnosis <진단> --rx <처방약>`
   - 가족력 → `14health history add --relation <관계> --disease <질환>`
3. **입력 후**: 저장된 노트 경로를 사용자에게 알려주고, 이상 수치가 보이면
   `/위험분석` 실행을 제안한다.

## 개인정보 규칙 (필수)

- 사용자가 실명을 말하면 **저장 전에 반드시 관계호칭으로 변환**한다.
  반복 등장하는 이름은 `14health alias add <실명> <관계호칭>` 으로 등록해 자동 치환.
- 건강 수치·증상·처방약을 vault 밖(웹 검색, 외부 API, git, 노션 본문)으로 보내지 않는다.
- 표준 수치 항목명: 수축기혈압, 이완기혈압, 공복혈당, 당화혈색소, 체중, 신장, BMI,
  허리둘레, 총콜레스테롤, LDL, HDL, 중성지방, AST, ALT, 감마GTP, 크레아티닌, 혈색소
