# 공단 사이트에서 공식 파일 받는 법

`14health official` 이 읽는 두 문서 — **건강검진 결과 통보서**와 **진료받은 내용
통보서** — 를 국민건강보험공단 사이트에서 직접 받는 절차다. **로그인·인증은
공단 사이트에서 사용자가 직접 하고, 14health는 다운로드된 파일만 읽는다** —
간편인증·공동인증서 정보가 앱을 거치는 일은 없다.

## 1. 건강검진 결과 — 건강iN

**사이트**: <https://hi.nhis.or.kr>  (모바일: <https://m.nhis.or.kr/hi>)

1. 건강iN 접속 → 로그인 (공동인증서·카카오·PASS·네이버·KB모바일 인증서 중 선택)
2. 상단 메뉴 **건강검진 → 검진결과조회**
3. 조회할 연도 선택 → 결과 확인
4. 화면 우측(또는 하단)의 **인쇄/출력** 또는 **PDF 저장** 버튼으로 다운로드
   - 최근 10년치 일반건강검진·암검진 결과를 조회할 수 있다
   - 검진 후 결과가 공단 시스템에 반영되기까지 2~4주(최대 1개월) 걸릴 수 있다

저장한 파일을 그대로 넣으면 된다:

```bash
14health official ~/Downloads/건강검진결과.pdf --relation 나
```

## 2. 진료·투약 내역 — 국민건강보험 홈페이지 "건강모아"

**사이트**: <https://www.nhis.or.kr>

1. 국민건강보험 홈페이지 접속 → 로그인
2. **건강모아 → 나의건강관리 → 나의 의료이용 정보**
3. 최근 5년간 방문한 의료기관·약국 목록에서 원하는 기간 조회
4. 진료일자·처방 횟수·투약일수·처방약 품명이 나온 화면을 **인쇄/PDF 저장**

```bash
14health official ~/Downloads/진료받은내용.pdf --relation 나
```

## 3. (참고) 심사평가원 — 내 진료정보 열람

**사이트**: <https://www.hira.or.kr> → 조회·신청 → **내 진료정보 열람**

요양급여 관점의 진료 정보(요양개시일·본인부담금·청구액)를 별도로 확인할 수
있다. 공단 사이트와 항목이 조금 다르므로, 진료비 관련 내역이 더 필요하면
여기서도 받아 같은 방식으로 넣으면 된다.

## 4. 앱에서 처리되는 흐름

```
공단 사이트 로그인·인증 (사용자가 직접, 공단 서버에서만 일어남)
        ↓
PDF/화면 저장 (내 컴퓨터·폰에 다운로드)
        ↓
14health official <파일>  또는  웹앱 입력 탭 › 📑 공식 파일
        ↓
문서 종류 자동 판별(검진결과/진료내역) → 실명·등록번호 제거 → 폼에 수치 프리필
        ↓
확인 후 저장 → 옵시디안 vault (관계호칭으로만 기록)
```

- 파일 형식은 **PDF·TXT**를 지원한다. PDF는 `pdftotext`(poppler-utils)가 있어야
  텍스트를 뽑는다 — 없으면 설치 안내가 뜬다(`apt install poppler-utils`).
- 여러 파일을 한 폴더에 모아 한 번에 넣을 수도 있다: `14health official ~/Downloads/공단자료/`
- 관계호칭을 파일에서 못 찾으면(성명이 가족 별칭에 등록 안 됨) `--relation` 으로 지정한다.
- 저장되는 것은 **수치·진료 내용뿐**이다. 성명·등록번호는 저장 전에 자동으로 지워진다.

## 자주 겪는 문제

| 증상 | 원인 · 해결 |
|---|---|
| "지원하지 않는 형식" | PDF·TXT가 아닌 화면 캡쳐(PNG/JPG)라면 `official` 대신 입력 탭의 **📷 사진** 방식을 쓴다 |
| "poppler-utils 필요" | `sudo apt install poppler-utils` (Tab S9 proot도 동일) |
| 수치가 하나도 안 잡힘 | 공단 PDF는 표 레이아웃이 문서마다 조금씩 다르다 — 추출 결과를 확인하고 부족한 항목은 직접 입력 방식으로 보충 |
| "대상을 알 수 없습니다" | `14health alias add <성명> <관계호칭>` 으로 미리 등록하거나 `--relation` 지정 |
