# S26 · Tab S9 역할 분담 (14health)

기존 PKS 구성(`Galaxy Tab S9 + S26 PKS 시스템 설계`)과 같은 원칙을 따른다 —
**Tab S9은 항상 켜진 서버, S26은 실제로 손에 들고 쓰는 기기.** 14health도
이 구조 위에 얹는다.

```
┌───────────────────────────────────────────┐
│  Galaxy Tab S9 (메인 서버)                 │
│  • proot Ubuntu 안에 14health 설치         │
│  • 14health app --lan  (상시 실행)         │
│  • n8n — 워크플로우 4종 (docs/n8n-…)       │
│  • Claude CLI (proot) — 스킬로 정밀 판독   │
│  • vault: /root/obsidian (Syncthing 원본)  │
└──────────────────┬──────────────────────────┘
                    │ Tailscale (100.112.74.84)
┌──────────────────▼──────────────────────────┐
│  Galaxy S26 (일상 사용 기기)                │
│  • 브라우저로 14health 앱 접속               │
│  • 영수증·검진지 카메라 촬영                 │
│  • Claude 모바일 앱 — 대화로 입력·질문       │
│  • 텔레그램 — n8n 알림 수신                  │
└───────────────────────────────────────────┘
```

## Tab S9 — 서버 역할

| 작업 | 명령 · 문서 |
|---|---|
| 최초 설치 | `docs/tabs9-배포.md` |
| vault 위치 | `/root/obsidian` (Syncthing 폴더 안 → S26·S23U 자동 동기화) |
| 앱 상시 실행 | `nohup 14health app --lan > ~/14health.log 2>&1 &` |
| n8n 워크플로우 | `docs/n8n-워크플로우.md` — 주간 리포트·검진주기·실비 미청구·영수증 감시 |
| MCP 서버 등록 | `claude mcp add 14health -- 14health mcp` (proot 안) |
| 정밀 이미지 판독 | `cd /root/14health && claude` → `/검진분석` (tesseract보다 정확) |
| 배터리 유지 | 설정 → 배터리 → Termux → 제한 없음, 상시 충전 |

**Tab S9에서만 할 것**: n8n 워크플로우 생성/수정, `14health.log` 확인, proot
안에서 `pip install -e .` 재실행(코드 업데이트 시), Claude CLI로 정밀 판독이
필요한 영수증·결과지 처리.

## S26 — 사용 기기 역할

| 작업 | 방법 |
|---|---|
| 앱 접속 | 브라우저에서 `http://100.112.74.84:<port>/?t=<토큰>` (Tab S9 실행 시 출력되는 주소) |
| 영수증·검진지 촬영 | 앱 입력 탭 › 📷 사진 (카메라 바로 열림) — 촬영 즉시 자동매칭·프리필 |
| 대화로 입력 | Claude 모바일 앱에서 `/건강입력` `/위험분석` (Tab S9 저장소에 붙어 작업) |
| 공식 파일 받기 | 공단 사이트 로그인은 S26에서 직접, 다운로드한 PDF는 앱 입력 탭 › 📑 공식 파일에 경로 입력 — `docs/공식파일-받기.md` |
| 알림 확인 | 텔레그램(n8n) — 수치·병명 없는 마스킹 요약만 옴, 상세는 앱에서 확인 |
| 옵시디안으로 직접 보기 | Syncthing으로 동기화된 로컬 vault 폴더를 옵시디안 앱으로 열람 |

**S26에서만 할 것**: 공단 사이트(건강iN·nhis.or.kr) 인증·로그인, 카메라 촬영,
일상적인 입력·조회. **S26은 서버를 켜지 않는다** — Tab S9이 꺼져 있으면 앱
접속도, n8n 알림도 멈춘다.

## 흔한 헷갈림 정리

- **"어디서 실행해야 하나?"** → 서버(앱·n8n)는 항상 Tab S9. S26은 클라이언트일 뿐.
- **"S26에서 직접 pip install 해도 되나?"** → 안 해도 된다. S26에는 14health를
  설치하지 않는다. 브라우저 접속만으로 충분하다.
- **"영수증을 S26에서 찍으면 Tab S9까지 어떻게 가나?"** → 사진은 앱(Tab S9 서버)으로
  바로 업로드된다 — 파일이 S26에 남지 않고, OCR·매칭·저장이 전부 Tab S9에서 일어난다.
- **"Claude CLI는 어디 껄 쓰나?"** → 정밀 판독·스킬 실행은 Tab S9 proot의 Claude CLI.
  S26의 Claude 모바일 앱은 대화형 입력 창구일 뿐, 실제 저장은 Tab S9 vault에 일어난다.
- **둘 다 꺼져 있으면?** → 아무 것도 동기화되지 않는다. 데이터 유실은 없다(vault는
  파일이므로) — 다음에 Tab S9을 켜면 이어서 쓸 수 있다.
